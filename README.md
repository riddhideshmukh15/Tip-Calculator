# 💰 Tip Calculator

## 📌 About the Project

Tip Calculator is a simple beginner-friendly Python project that calculates the tip amount and total bill based on the bill value and tip percentage entered by the user.

## ✨ Features

* Enter the bill amount
* Enter tip percentage
* Calculate tip amount
* Calculate total bill
* Display the final amount

## 🛠️ Technologies Used

* Python 3

## ▶️ How to Run

```bash
python tip_calculator.py
```

## 💻 Sample Output

```text
===== TIP CALCULATOR =====

Enter bill amount: ₹500
Enter tip percentage: 10

===== BILL =====
Bill: 500.0
Tip: 50.0
Total: 550.0
```
