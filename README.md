# 💰 Tip Calculator with GST Calculation

## 📌 About the Project
The Tip Calculator with GST Calculation is a simple Python project that calculates the GST amount, tip amount, and final bill based on the bill amount and the percentages entered by the user.

## ✨ Features
- Enter the bill amount.
- Calculate GST based on the GST percentage.
- Calculate the tip based on the tip percentage.
- Display the complete bill summary.
- Display amounts up to two decimal places.

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Run the Python file:

   ```bash
   python tip_calculator.py
   ```

## 🧮 Example
**Input:**
- Bill Amount: ₹1000
- GST: 5%
- Tip: 10%

**Output:**
- Bill Amount: ₹1000.00
- GST Amount: ₹50.00
- Tip Amount: ₹100.00
- Total Amount: ₹1150.00
